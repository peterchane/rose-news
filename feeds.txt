# Rose's news sources. Edit this file, then run:  npm run check:feeds
#
# One feed per line:   section | outlet name | rss url | weight | max age (hours)
#
#   section  world, business, tech, science, sports, or usc
#   outlet   name as it should read in the email
#   url      the RSS or Atom feed
#   weight   optional, 0.1-1.0, defaults to 1.0. Higher = preferred as the
#            link when several outlets cover the same story.
#   max age  optional, defaults to 30 hours. Raise it for outlets that don't
#            publish daily, or their stories will never be fresh enough to use.
#
# Lines starting with # are ignored. Blank lines are fine.
#
# Heads up:
#   - AP and Reuters no longer publish working public RSS feeds.
#   - Paywalled outlets work fine, but Rose hits a paywall if she clicks.
#   - More outlets on one story = higher ranking, so adding a second outlet
#     with a similar slant amplifies that slant.
